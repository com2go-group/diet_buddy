# Data inventory

What DietBuddy stores, why, and how it's protected. It feeds the App Store privacy label and the Google Play Data Safety form (CLAUDE.md §13). **Update this file in the same change as any migration that adds, removes or repurposes personal data.**

Everything is stored in Supabase in an EU region and is only visible to the user it belongs to (row level security). Deleting an account deletes all rows (FK cascade) and the user's Storage files (account-deletion Edge Function).

| Data                                                                                    | Table                                                               | Category                  | Purpose                                     | Special-category (GDPR art. 9)     | Shared with third parties                                           |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------- | ------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------- |

Not collected in Phase 1: precise location, contacts, advertising ID (arrives with AdMob in Phase 2, behind UMP consent), analytics and crash data (PostHog/Sentry, later).
